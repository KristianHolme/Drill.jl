## Added

- Learning rate schedules: `learning_rate` in `PPO` and `SAC` takes a number or a schedule, a function of the training progress (fraction of `max_steps` taken, from 0 to 1).
  New `LinearSchedule`, `CosineSchedule` and `ExponentialSchedule`; any function `p -> lr` also works.
  The rate is updated after each rollout (PPO) or collection step (SAC), also on Reactant without recompiling.
- `training_progress(cache)` and `adjust_learning_rate!(learner, eta)`, the in-place version of `set_learning_rate`.
- UnicodePlots extension: with UnicodePlots loaded, schedules show as a plot in the REPL, and `lineplot(schedule)` returns the plot.

## Changed

- The logged `train/learning_rate`, the progress meter and `cache.stats[:learning_rates]` show the current learning rate instead of the fixed `alg.learning_rate`.
- `PPO` and `SAC` have an extra type parameter for the learning rate type. `SAC` no longer requires `learning_rate` to have the same float type as `tau` and `gamma`.
